# TerraBela Farm — Rio e Pontes v1

Pacote com assets individuais para montar um rio no estilo cozy farm, incluindo tiles de rio, faixas de margem decorativa e duas pontes diferentes.

## Estrutura
- `assets/bridges/` — pontes e acessos.
- `assets/river_tiles/` — tiles principais do rio.
- `assets/banks/` — faixas decorativas de margem/grama.
- `previews/` — pranchas originais para referência.
- `docs/manifest.json` — mapa dos arquivos.
